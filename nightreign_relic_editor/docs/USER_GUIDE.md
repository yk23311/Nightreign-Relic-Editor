# 使用说明

> 本工具仅供学习研究与**离线 / 私人测试**环境使用。禁止在线作弊、反作弊绕过、联机篡改。

## 准备

1. 仅在**离线**环境启动游戏，并**进入存档**（没进存档读不到遗物）。
2. 安装依赖并启动：

```bat
cd Nightreign-Relic-Editor\nightreign_relic_editor
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

界面依赖系统的 **WebView2 运行时**（Win11 自带，Win10 多数也有）。缺失时程序会弹提示并给出下载地址。

## 界面：卡片工作台

6 个遗物槽各一张卡片同屏。每张卡片上是 3 个属性 + 3 个减益。

### 三步走

1. **附加**：点顶部「附加进程」，状态灯变绿即可（首次约几秒，在后台执行，不会卡界面）
2. **选中**：点**卡片标题**选中该槽 —— 不用去点那个小方框
3. **改 + 应用**：点卡片上的词条行改词条 → 看右侧「待应用改动」→ 点「应用到选中」

> **所有修改都是先暂存、后应用。** 手动改词条、复制粘贴、套预设，全部先进入右侧的
> 「待应用改动」列表，你可以逐条检查、看校验结果，确认无误再一次性写入内存。

### 好用的操作

| 操作 | 怎么做 |
|------|--------|
| 改一个词条 | 点那一行 → 候选列表里搜名称或 ID → 点选 |
| 手输任意 ID | **高级模式**下，候选列表底部有「手动 ID」输入框 |
| 交换属性顺序 | 在卡片内把一行**拖到**另一行上 |
| 把词条搬到别的槽 | 把一行**拖到**另一张卡片上 |
| 复制整套词条 | 卡片标题右侧「复制」→ 选中目标槽 → 顶部「粘贴槽N 到选中」 |
| 批量 | 多选卡片标题 → 改词条 → 应用到选中（>6 项会二次确认） |
| 存/套预设 | 右侧「预设」区：把选中槽存为预设、或把预设套用到选中的槽 |
| 备份/恢复 | 顶部「备份」写快照；「恢复备份」回到快照（会二次确认） |
| 撤销/重做 | 顶部按钮，栈深 20 |

## 模式

| 模式 | 说明 |
|------|------|
| 只读预览（默认） | 只能看不能写；改动仍可暂存，但「应用」会被拒绝 |
| 编辑 | 取消勾选「只读预览」后可写 |
| 高级模式 | **取消全部合法性检查**，并把属性/减益候选都换成 CT 全量表 |

高级模式下额外获得两项能力：

1. **跨类选择**：属性 1–3 与减益 1–3 的候选都列出 **CT 全量表（`RelicID`）的 1076 条**，
   按 CT 自带的 8 个分组用不可选标题分隔：
   攻击 / 角色 / 装备 / FP·HP 恢复 / 潜伏之力 / 杂项 / 诅咒 / **非法**。
   这与 CE 里「高级模式 → 玩家 → 遗物编辑器」看到的内容完全一致。

   > **「非法」组（579 条）**：CT 作者自己把它们标为非法，compatibility 全部是 `N/A`，
   > 且与安全模式的三张表**零重叠**。CE 里同样可以选到它们，本程序为保持一致也列出。
   > 写入这些 ID 的后果未知，请自行判断。该组在候选列表里**默认隐藏**，可取消勾选显示。

2. **手动 ID**：可把任意 u32 写进指定字段。支持 `7001400`、`0x6ADB30`、`-1`（等于清空）。

> 高级模式是给知情用户的逃生口，不是「更方便的编辑模式」——
> 它允许写入游戏内非法的组合，可能造成存档异常。

## 校验与「应用」置灰

右侧「规则校验」实时跑 CT 规则：兼容性 / Roll_Order / Roll_Group / Req_Debuff / 空位连续。

**只要存在阻断性冲突，「应用到选中」就会被置灰**，按钮上显示「· 有 N 项冲突」，
同时「待应用改动」里非法的那几条会标红打 ✗，鼠标悬停可看具体原因。

这样设计是因为：后端本来也会拒绝，与其让你白点一次再吃一个错误弹窗，不如当场说清楚。

> 常见情形：在**高级模式**下配好一套改动，切回**安全模式**后它们可能不合法。
> 此时改动**不会被丢弃**，只是被标出来 —— 修好或清空即可恢复可点。

## 常见问题

| 现象 | 处理 |
|------|------|
| 附加失败 | 管理员运行；确认进程名 `nightreign.exe`；确认已进入存档 |
| 附加成功但读不到遗物 | 同上 —— 未进存档时符号能解析但槽位为空 |
| 符号解析失败 | 先看 `data/logs/` 的日志（含未命中的 AOB 与模块）；再改 `data/mapping.json` 的 `aob` / `aob_offset` |
| 「应用」点不动 | 看按钮文案：若显示「有 N 项冲突」就去右侧修；若仍勾着「只读预览」也会不可用 |
| 界面白屏 / 一直不动 | 看 `data/logs/` 里有没有「界面已就绪」；没有则是 WebView2 初始化失败，重启程序 |
| 提示缺少 WebView2 | 按弹窗给的微软官方链接装「Evergreen Bootstrapper」 |
| 空槽显示「(空)」 | 正常：内存中的空位 0xFFFFFFFF 会被归一化为 -1 |
| 候选里看到「[当前值] 未知」 | 正常：该 ID 不在枚举里（高级模式写的怪 ID），界面把它补进列表以免被误清掉 |

## 日志

`data/logs/app-YYYYMMDD.log`（源码态在项目根，打包后在同目录）。
反馈问题时请附上该文件 —— 界面上的错误提示只是摘要，完整 traceback 在日志里。

## 安全规则（**程序不再替你拦截，务必自己遵守**）

0.6.0 起 RNG 安全门已彻底移除，程序不会阻止你修改任何遗物。修改前请自行确认：

1. 卸下要改的遗物（可能还需要把它从预设和其他角色身上移除）。
2. 打开**出售菜单**，看它能否被**高亮选中**——不要真的卖掉。
3. 能选中 → 随机(RNG)遗物，**安全**。
4. **不能选中 → 唯一遗物，不要改，否则账号会被标记。**

- 不要改 1.02 及更早版本的遗物。
- 不要用于联机。
